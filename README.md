# 🔎 Path Finder

A simple web-based **File Path Finder** built using **Python, Flask, HTML, and CSS** that helps users locate files on their computer by searching for a file name.

## 🚀 Features

* 🔍 Search for files by entering their name.
* 📂 Finds the location/path of matching files on the computer.
* ⚡ Uses Python for file-system searching and processing.
* 🌐 Flask connects the Python backend with the web interface.
* 🎨 Simple and user-friendly HTML & CSS interface.

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **HTML5**
* **CSS3**

## ⚙️ How It Works

1. Enter the name of the file you want to find.
2. The Flask application receives the search request.
3. Python searches the computer's file system for matching files.
4. The application displays the file path in the web interface.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd Path-Finder
```

### 2. Install Flask

```bash
pip install flask
```

### 3. Run the application

```bash
python app.py
```

### 4. Open in your browser

```text
http://127.0.0.1:5000/
```
